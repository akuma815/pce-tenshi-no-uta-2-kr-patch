천사의 시 II ~타천사의 선택~ (PC Engine Super CD-ROM²) 한글화 v1.0.1
=====================================================================

구성
  Tenshi2KR_Patcher.exe           패치 + 바로가기 생성 프로그램 (xdelta3 내장)
  Tenshi_no_Uta_II_KR_disc.xdelta 디스크 이미지 패치 (단일 bin 덤프용)
  Tenshi_no_Uta_II_KR_track02_redump.xdelta 데이터 트랙 패치 (Redump 멀티 bin 덤프용, Track 02 만 교체)
  SystemCard3_KR.xdelta           시스템 카드 패치
  cue_template.cue                패치된 이미지용 cue (프로그램이 자동 생성에 사용)
  *_from_v1.0.xdelta (2개)        v1.0(또는 v0.3) 결과물을 v1.0.1 로 올리는 패치 (디스크 단일 bin·Redump Track 02)
  SystemCard3_KR_from_v0.3.xdelta  v0.3 시스템 카드를 올리는 패치 (v1.0 카드는 v1.0.1 과 같아 그대로 씀)

준비물 (직접 마련)
  1) 원본 디스크 이미지 (둘 중 하나)
     a. 단일 bin + cue 덤프: bin 523,184,384 바이트, SHA-1 67ec659f387accd4544057a8bff4ab84bf5e153b
     b. Redump 멀티 bin 덤프(트랙별 34개 파일): Track 02 가 22,466,304 바이트,
        SHA-1 e0a7dbed4f3f4d57d4bb044cb1520aa26c0324d4 (오디오 트랙은 그대로 씀)
  2) 원본 시스템 카드: Super System Card 3.0 (J), 256KB
       SHA-1 79f5ff55dd10187c7fd7b8daab0b3ffbd1f56a2c
       (앞에 512바이트 헤더가 붙은 262,656B 덤프도 됩니다. 헤더를 떼고 패치하며 결과는 헤더 없는 256KB)
  3) 에뮬레이터 (아래 "지원 에뮬레이터" 참고)

사용법 (파일은 버튼으로 고르거나 입력칸에 끌어다 놓습니다)
  1. Tenshi2KR_Patcher.exe 실행 (xdelta 파일들과 같은 폴더에서)
  2. [1] 원본 디스크 이미지 .cue 지정 (단일 bin 또는 Redump 멀티 bin)
  3. [2] 원본 시스템 카드 .pce 지정
  4. [3] BizHawk 의 EmuHawk.exe 지정 (선택 사항 — BizHawk 를 쓸 때만)
  5. [패치 + 바로가기 만들기] 클릭
       - 단일 bin: 같은 폴더에 *_KR.bin, *_KR.cue 생성 (원본과 같은 크기)
       - 멀티 bin: 같은 폴더에 '(Track 02)_KR.bin' 과 *_KR.cue 생성 (다른 트랙 파일은 원본 그대로 참조하므로 옮기지 말 것)
       - 시스템 카드: 같은 폴더에 SystemCard3_KR.pce 생성 (256KB)
       - EmuHawk 를 지정했으면: BizHawk 폴더에 config_tenshi2kr.ini(기존 config.ini 복사 + 한글 카드 지정)를 만들고
         바탕화면과 게임 폴더에 '천사의 시 II 한글판' 바로가기를 만듭니다.
         또 BizHawk 의 gamedb\gamedb_pce_hucards.txt 에 한글 카드를 한 줄 등록합니다(PCEHawk 코어용, 아래 참고).
         처음 한 번 원래 파일을 gamedb_pce_hucards.txt.bak_tenshi2kr 로 백업합니다.
  6. 아래 표대로 에뮬레이터에 *_KR.cue 와 SystemCard3_KR.pce 를 지정해 실행.

지원 에뮬레이터 (v1.0.1; v1.0 과 같음)
  확인함
    - BizHawk 2.11 (TurboNyma 코어)        : 패처가 바로가기를 만들어 줍니다. (권장 코어)
    - BizHawk 2.11 (PCEHawk 코어)          : 패처에 EmuHawk.exe 를 지정해 gamedb 에 한글 카드가 등록된 경우에만 됩니다.
        PCEHawk 는 시스템 카드를 해시로 알아보고, 등록된 카드에만 슈퍼 CD-ROM² 추가 RAM 을 켭니다.
        미등록이면 시작할 때 '알 수 없는 BIOS' 경고가 뜨고, 이어하기·새 게임 뒤 화면이 전부 깨집니다.
        (0.3 패처로 등록했다면 '알려진 배드 덤프' 경고가 떴습니다 — 등록 줄의 상태 표시가 잘못됐던 것으로,
         1.0 패처에 EmuHawk.exe 를 지정해 한 번 실행하면 고쳐져 경고가 사라집니다.)
    - Mednafen 1.32.1 (pce 코어, pce_fast 코어 둘 다)
        mednafen.cfg 의 pce.cdbios / pce_fast.cdbios 를 SystemCard3_KR.pce 경로로 바꾸고 *_KR.cue 를 엽니다.
    - RetroArch (Beetle PCE 계열 코어)      : system 폴더의 syscard3.pce 를 SystemCard3_KR.pce 로 교체
                                               (원본 syscard3.pce 는 다른 곳에 백업해 두세요)
    - PCE.emu (안드로이드)                   : 설정에서 시스템 카드 파일을 SystemCard3_KR.pce 로 지정
  구조상 가능하지만 확인하지 못함
    - Mesen2, Geargrafx
  지원 안 됨
    - ares : 시스템 카드 파일의 해시로 기종 구성을 정하기 때문에, 수정된 카드는 슈퍼 CD-ROM² 로 인식되지 않습니다.

1.0(또는 0.3) 에서 1.0.1 로 올리기
  방법 A. 원본 이미지가 있으면: 위 사용법 그대로 원본 .cue 와 원본 카드를 지정하세요. 같은 폴더의 *_KR 파일이 1.0.1 로 덮어써집니다.
  방법 B. 1.0 결과물만 있으면: [1] 에 1.0 의 *_KR.cue, [2] 에 1.0 의 SystemCard3_KR.pce 를 지정하세요.
          패처가 SHA-1 로 확인한 뒤 디스크(또는 Track 02)를 그 자리에서 1.0.1 로 바꿉니다. 시스템 카드는 1.0 과 같아 그대로 둡니다.
          0.3 결과물도 같은 방법으로 됩니다(0.3 디스크는 1.0 과 내용이 같고, 0.3 카드는 패처가 올려 줍니다).
          에뮬레이터에서 파일을 열어 둔 채로는 바꿀 수 없으니 먼저 닫으세요.
          수동으로 하려면 xdelta 도구로 *_from_v1.0.xdelta 를 1.0 의 *_KR.bin(단일 bin) 또는 (Track 02)_KR.bin 에 적용하면 됩니다.
  세이브: 게임 안 세이브(이어하기)와 에뮬레이터 세이브 파일(파일 이름이 같음)은 그대로 이어집니다.
          에뮬레이터 상태 저장(퀵세이브·스테이트)은 1.0 것도 쓰지 마세요.

1.0.1 에서 바뀐 것 (1.0 대비)
  - 펨브로크 항구 카지노에서 도박사 소녀에게 「네」 → 「좋아, 간다!」 직후 화면이 검게 멈추던 문제 수정.
    원인은 카드 미니게임 모듈 초기화의 VBlank 인터럽트 경합(원본에도 잠재한 타이밍 문제가 한글판에서 드러남)으로,
    모듈의 초기화 코드 9바이트만 고쳤습니다. 디스크 이미지의 다른 부분과 시스템 카드는 1.0 과 같습니다.
  - 덩치 큰 보스가 마법 목록 창 위에 겹쳐 보이는 것은 원본도 같아 그대로 두었습니다.

0.3 에서 1.0 으로 올리기
  방법 A. 원본 이미지가 있으면: 위 사용법 그대로 원본 .cue 와 원본 카드를 지정하세요.
          같은 폴더의 *_KR 파일이 1.0 으로 덮어써집니다(이름이 같아 세이브가 이어집니다).
  방법 B. 원본은 지웠고 0.3 결과물만 있으면: [1] 에 0.3 의 *_KR.cue, [2] 에 0.3 의 SystemCard3_KR.pce 를 지정하세요.
          패처가 0.3 결과물인지 SHA-1 로 확인한 뒤, 그 파일들을 그 자리에서 1.0 으로 바꿉니다.
          (1.0 은 디스크 이미지가 0.3 과 같고 시스템 카드만 바뀝니다.)
          에뮬레이터에서 파일을 열어 둔 채로는 바꿀 수 없으니 먼저 닫으세요.
          수동으로 하려면 xdelta 도구로 SystemCard3_KR_from_v0.3.xdelta 를 0.3 의 SystemCard3_KR.pce 에 적용하면 됩니다.
  0.1·0.2 를 쓰고 있었다면: 원본 이미지로 방법 A 를 쓰세요. (원본이 없으면 0.3 패처로 먼저 0.3 으로 올린 뒤 방법 B)

  세이브
    - 게임 안에서 한 세이브(이어하기)는 1.0 에서도 그대로 쓸 수 있습니다.
      BizHawk(*_KR.SaveRAM)·RetroArch·Mednafen 모두 0.3 과 파일 이름이 같아 그대로 이어집니다.
    - 0.1·0.2 의 Mednafen 세이브는 이름에 디스크 구성 값이 들어 있어서 이름을 바꿔 줘야 이어집니다.
      mednafen 폴더의 sav 안에서
        <이미지 이름>.c7ac61b0cd9ece85dedf652370f81734.sav  (0.1·0.2)
      를 복사해 이름을
        <이미지 이름>.c62f2abf2f73a81b986dec23f3e07684.sav  (0.3·1.0)
      으로 바꾸세요. (1.0 으로 한 번 실행하기 전에 바꾸는 것이 안전합니다)
    - 에뮬레이터 상태 저장(퀵세이브·스테이트)은 이전 버전 것을 쓰지 마세요(0.3 것도 안 됩니다). 대사가 깨지거나 음악·영상이 어긋납니다.

1.0 에서 바뀐 것 (0.3 대비 — 자세한 내용은 카페 글)
  - 편지·지도 그림 등에 「(0B)」 같은 글자가 찍히던 문제 수정 (편지는 ▽ 에서 버튼을 누를 때마다 한 줄씩 넘어갑니다).
  - 가게 대사 정리: 「매번 감사합니다」 같은 직역 인사를 자연스럽게, 「〜 객주」 → 「〜정」 으로 통일,
    가게 주인 말투를 원문(반말·존댓말)에 맞춤, 구매/팔기 때 묻는 말, 가게 이름 오역(괴짜·시간의 강물정 등).
  - 오역 수정: 「오스！」(구호), 「그래도 깎아 줄 순 없어」, 「제 이름은 리아나」, 리아에게 묻는 말의 물음표 등.
  - 가게 이름 같은 「…」 안의 짧은 말이 줄 중간에서 잘리지 않게 줄바꿈 규칙 개선.
  - BizHawk PCEHawk 코어의 '알려진 배드 덤프' 경고 제거 (위 지원 에뮬레이터 참고).

0.3 에서 바뀐 것 (0.2 대비)
  - 마을 진입 때 검은 화면 멈춤, 이벤트 영상 음성이 약 13.6초 늦던 문제, 첫 탑 뒤 컷신 그래픽 깨짐, 스태프 크레딧 깨짐 수정.
  - 이름·지명·아이템 표기 통일, 메뉴 띄어쓰기, 말줄임표 통일, 미번역 전투 메시지, 한자음 직역 표기 수정.

알려진 제한
  - 이벤트 영상(비주얼 씬)의 음성 대사에는 자막이 없습니다 (원본에도 자막이 없습니다).
  - 컷신 뒤와 엔딩의 스태프 크레딧은 원본 일본어 그대로입니다.

주의
  - 원본 파일은 수정하지 않습니다. 결과물은 항상 새 파일로 만듭니다.
  - 체크섬이 다른 덤프(다른 리핑)는 패치가 거부됩니다.
  - 기존 BizHawk 설정(config.ini)은 건드리지 않고 복사본(config_tenshi2kr.ini)만 씁니다.
  - 엔딩까지 플레이로 확인한 정식판입니다. 그래도 깨진 글자·멈춤·잘못된 번역·어색한 문장을 발견하면
    화면 캡처와 함께 (가능하면 어느 마을/장면인지도) 알려 주세요.
