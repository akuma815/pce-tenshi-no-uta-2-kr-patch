# 번역 시트 사용 안내

`script_sheet.tsv` — `tools/extract_script.py`가 `extracted/Track02_data.iso`에서
자동 추출한 번역 작업용 대조표. UTF-8(BOM) 탭 구분이므로 엑셀/구글시트에서 바로 열린다.

## 열 구성

| 열 | 내용 |
| --- | --- |
| 키(ISO오프셋) | 원문 문자열 시작의 ISO 파일 오프셋(16진수). **후킹 룩업 테이블의 키가 되므로 수정 금지** |
| 영역 | `slotNN`(마을/던전 №N), `system`(전투·메뉴), `card`(카드 미니게임), `boot`(오프닝), `late`(세이브 등), `misc` |
| 중복그룹 | `=오프셋` 표기가 있으면 해당 그룹 대표 행과 동일한 원문. **대표 행만 번역하면 나머지는 자동 적용 예정** |
| 원문 | 디코딩된 일본어 원문 |
| 번역 | 한국어 번역 입력란 (빈칸) |

## 원문 안의 마커 (번역문에도 규칙 유지)

- `\n` : 줄바꿈 — 메시지창은 자동 줄바꿈이 없으므로 번역문도 창 폭에 맞게 직접 넣어야 함
- `\p` : 페이지 넘김 (창 클리어)
- `{#5}` 등 : 텍스트 색상 변경 — 화자 이름 앞뒤에 자주 옴, 위치 유지
- `{%d}` `{%x}` `{%s}` : 숫자/문자열 변수 삽입 — 반드시 번역문에도 포함
- `{~}` : 커서 1타일 전진 (공백)
- `{0B}` `{0E}` : 기타 제어 코드 — 위치 유지

## 알려진 한계

- 자동 추출이므로 소량의 그래픽 오탐 행이 남아 있을 수 있음 → 번역란을 비워 두면 무시됨
- 런이 그래픽에서 시작해 진짜 텍스트로 이어진 행은 원문 앞부분에 쓰레기 문자가 붙어 있을 수
  있음 (예: `タあタお…次の目的のこと`) → 진짜 부분만 번역하면 됨. 키 보정은 후킹 단계에서 수행
- 아이템/몬스터명 등 히라가나가 없는 짧은 명사 테이블은 이 시트에 포함되지 않음 (별도 단계)

## 통계 (2026-07-12 기준)

- 총 10,603행 / 고유 원문 3,137개 / 고유 원문 분량 약 145,000자
- 중복이 많은 이유: 동료 대화 등이 지역 슬롯마다 복제 수록되어 있기 때문
- **기존 번역(translate_original/) 병합 결과: 9,812행(92.5%) 채움, 고유 원문 기준 2,879/3,137(91.8%)**

## 기존 번역 병합 (`tools/merge_translations.py`)

`translate_original/`의 기존 번역(대사/3줄초과/크레딧/UI xlsx, visualscene csv)을
정규화 텍스트 매칭으로 시트에 채운다. 매칭 규칙:

- 마커·마크업(`\n` `\p` `#5` `%f0` `{…}` 공백) 제거 후 대조
- 그래픽 쓰레기 접두는 절단 재시도로 흡수 (행 전체 매칭은 8자 제한 — 과절단 방지)
- 페이지 분할이 어긋난 경우 빅스트링 부분문자열 매칭 (커버리지 90% 이상만)
- `3줄초과_수정필요.xlsx`가 `대사_번역.xlsx`를 덮어씀 (수정본 우선)

채워진 ko에는 게임 네이티브 마크업(`%f0`, `#5화자：\n#1…`)이 보존되어 있어
재삽입 단계에서 그대로 쓸 수 있다.

## 미번역분: `missing_translations.csv`

병합에서 매칭되지 않은 **고유 원문 258개** (등장횟수 병기):

- 약 130개 = 그래픽 오탐 (원문이 뜻 없는 가나 조합 — 번역란 비워두면 됨)
- 약 128개 = 실제 번역 필요분: 세이브/파일 오류 메시지(late), `%s`/`%d`로 시작해
  원문이 잘린 전투·시스템 메시지, 페이지 중간에 `{%f}` 커맨드가 낀 일부 대사 등

이 CSV의 번역 열을 채운 뒤 `merge_translations.py`를 다시 돌리면 시트에 반영된다
(추가 소스로 읽도록 확장 예정).

## 재실행

```text
python tools/extract_script.py       # 시트 재생성 (번역 열 초기화됨)
python tools/merge_translations.py   # 기존 번역 병합 + missing CSV 생성
```
