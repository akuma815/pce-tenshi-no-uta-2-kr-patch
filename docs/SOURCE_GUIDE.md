# 공개 소스 안내

분석·추출·재삽입·빌드 스크립트, 번역 원장(XLSX/CSV/JSON), 설정과 작업 문서를 원래 상대 경로로 보존했습니다. 이 저장소는 2026-10-16 작업 폴더에서 선별한 소스 스냅샷입니다. 공식 v1.0(b64)의 재현은 [소스 재빌드 안내](REBUILD_B64_2026-10-16.md)를 따릅니다.

원본·BIOS·추출 바이너리·이미지·영상·세이브·QA 덤프·캐시·외부 실행 파일은 Git 추적에서 제외했습니다. 2026-10-16에 중간 카드 복원 차분, 고정 글꼴과 디스어셈블러 소스를 추가했습니다. 보유한 원본·외부 도구를 공급하면 공식 v1.0 코어를 재빌드할 수 있습니다. 역사적 실험 스크립트 전체의 재현을 뜻하지 않습니다.

번역 원장은 그대로 보존했으며 번역문·행 상태를 일괄 수정하지 않았습니다. 소스 스냅샷과 기존 최종 배포본의 빌드 시점은 다를 수 있으며, 배포 파일은 README와 릴리즈에 고정한 기존 최종본입니다.

## 검증 범위

최초 공개 준비의 패키지 검사에 더해, 2026-10-16에는 b64 소스 재빌드와 공식 v1.0 패치 적용을 수행했습니다. BIN·CUE·시스템 카드·Redump Track 02 출력 해시가 일치했습니다. 새 GUI 실행 파일의 바이트 재현, 에뮬레이터 실행 또는 전체 플레이 검수는 수행하지 않았습니다. 과거 검증 결과는 배포 안내와 원래 작업 기록의 해당 버전·범위에 한정됩니다. 기존 문서의 로컬 산출물·QA 링크는 공개 저장소에 포함되지 않을 수 있습니다.

게임과 외부 도구·폰트의 저작권 및 라이선스는 원 권리자의 조건을 따릅니다. 배포 ZIP의 도구·라이선스·소스 제공 파일을 함께 보존했습니다.
