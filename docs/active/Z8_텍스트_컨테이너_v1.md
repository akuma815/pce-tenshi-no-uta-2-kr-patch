# Z8 텍스트 컨테이너 v1

Z7의 module/family 분류와 로컬 글리프 맵을 사용해 전체 번역을 엄격하게 인코딩한 분석 컨테이너다. 아직 게임이 소비하는 runtime pointer/index 형식은 아니다.

- 물리 레코드: **18817개**
- 텍스트 컨테이너: **103개**
- 원본 raw/ISO 일치 및 보호 원문 디코딩: **18817개 전부 PASS**
- 원문/번역 제어 토큰 순서 불일치: **0건**
- 미매핑 문자: **0건**
- 명시적 중점 인코딩 별칭: **12행 / 24회** (`U+00B7` → `A5`, 원본 CSV 불변)
- category/subcategory 의미 테이블: **25개**
- 고정 길이 후보: **6018개**
- 길이만으로 재배치가 필요한 항목: **12799개**
- 컨테이너 총량: **606950바이트**
- 최대 컨테이너: **17175바이트**

## 확정한 경계

- 모든 원본 엔트리는 `00`으로 종료하며 container 인코더도 끝에 정확히 한 번 생성한다.
- `0B`, `0C`, `0D`, `0E`, `#x`, `%x`, `7E`는 원본과 번역에서 바이트 인자와 순서를 그대로 보존한다.
- 패키지 안에서 최종 인코딩 바이트가 완전히 같은 문자열만 dedup한다.
- 어떤 문자열도 8 KiB 경계를 넘지 않도록 배치한다.
- 과거 `01/02` redirect/continuation은 폐기 설계로 분류하며 재사용하지 않는다.

## 아직 확정하지 않은 경계

- renderer별 전체 참조/포인터 카탈로그
- loader-owned redirect 또는 index의 실제 바이트 형식
- 컨테이너를 읽을 RAM 주소, MPR 상태와 수명
- 고정 길이 후보를 제자리 치환할 수 있는 renderer별 패딩 규칙

따라서 v1 상태는 `STRUCTURE_PASS_RELOCATION_BLOCKED`다. 다음 게이트에서는 한 renderer family만 선택해 참조 분모와 loader-owned redirect를 먼저 증명한다.
