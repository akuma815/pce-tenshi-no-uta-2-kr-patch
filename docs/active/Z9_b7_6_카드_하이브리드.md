## 1. 설계

2882 는 정적 자산 지도 배제 후 후보 뱅크가 $7E/$7F 뿐(16,384B) < 텍스트
24,050B. 초과분은 **시스템 카드 ROM free 구간**에 둔다.

- **로더/리더/armchk 코드는 b7.5 와 바이트 동일 (검증기로 확인).**
  armchk 인덱스 엔트리의 bank 필드에 카드 뱅크 번호($01/$15 등)를 넣으면
  serve 의 `TAM #$20` 이 RAM 뱅크와 동일한 방식으로 카드 ROM 을 MPR5 에
  매핑한다 — 순수 데이터 확장.
- 2882 RAM 행 2개(씬 테이블 엔트리는 FF 종결이라 44B 형식 그대로):
  - 9206+0 4섹터 → **$7E** = 인덱스(1,271B) + [갭 텍스트 649B] +
    armchk@0x780(159B) + 텍스트 6,113B
  - 9210+4 4섹터 → **$7F** = 텍스트 8,184B
  - 복원 행 = 원본 씬 섹터 2970..2973/2974..2977 (무수정 확인)
- 카드 텍스트: bank $15 run(0x2AB40) 5,308B + bank $01 run(0x02CF9) 3,796B.
  레코드는 bin(단일 뱅크) 내 연속 — MPR5 창 침범 0 (검증기 확인).
- 배치 합계: RAM 58레코드 + 카드 113레코드 = 171 전량, 24,050B 정확 수용.
