# Z9 — 씬 패키지 정적 자산 지도 결과 (2026-08-23)

도구: `tools/analyze_ziria_z9_static_asset_map.py`
산출: `module_relink/z9_static_asset_map/` (manifest.json, global_asset_runs.tsv,
bank_verdicts.tsv, renders/*.png)

## 1. 목적

b7.4 교훈(씬 RAM cold = 위치 커버리지 × **상태 커버리지**)의 정적 보완.
아이템 아이콘처럼 소지 상태에 의존하는 read 는 플레이 CDL 로 전수 관측이
불가능하다 — 그 대상 자산을 정적으로 식별해 뱅크 선정에서 원천 배제한다.

## 2. 원리와 근거

**전역 동일 블록 = 엔진 고정 계약 자산.** 96섹터 씬 패키지 32개(고유 LBA)를
같은 씬-상대 오프셋끼리 16B 그래뉼로 비교하면, 사실상 전 씬(≥29/32)에서
바이트 동일인 블록이 나온다. 엔진이 고정 씬-상대 주소로 소비하는 자산은
모든 패키지에 같은 위치·같은 내용으로 실려야 하므로 여기 속한다.

반면 **소수 씬 공유(g=2~11, 인접 맵 패밀리의 중복 자산)는 배제 사유가
아니다**: b7.2 런타임 PASS 뱅크(290 $78 는 82.8%가 쌍 공유)가 강화 게이트를
통과했다. 전역 임계(0.9)가 런타임 증거와 모순 없는 유일한 경계다.
분포 실측: g=32 47,952B / g=21 18,528B / g=2 57,408B / 유니크 11,488B.

| 0x8000..0xBB00 | 15,104B | $6C..$6D | 노이즈성(압축 추정). 메뉴가 head 0x8000..0x94A0 소비(CDL 실측) |

### b7.4 아이콘 깨짐의 원천 특정 (HANDOFF §1 의 질문에 대한 답)

- 아이콘 타일 = **$6E 전체 + $6F 대부분** (0xC000..0xFF80, 약 508타일
  ≈ 127개 16×16 아이콘). b7.4 는 $6F 를 텍스트 뱅크로 덮었다 → 신규 획득
  아이템 아이콘 깨짐.
- $6D 앞 0x1B00 은 공유 자산 A(0x8000..0xBB00)의 꼬리 — b7.4 가 함께 덮음.
- **$7F 는 전역 자산이 아니다** (2882 에선 사실상 유니크+fill, g≥10 공유
  64B 뿐) — b7.4 깨짐에 $7F 는 무관했을 가능성이 높다.
- b7.1 메뉴 장비 아이콘 깨짐($6C/$6E 침범)도 같은 두 블록으로 설명된다.

| 씬 | 후보 뱅크 (전역·CDL hot 제외) | 텍스트 필요 | 후보 용량 | RAM 단독 |

**2882 는 RAM 단독 상주 불가가 수치로 확정.** 탑 컨텍스트는 나머지 뱅크를
전부 접근(CDL)하거나 전역 자산이다. 선택지(다음 단계 결정 사항):

1. **카드 하이브리드 (구조적으로 유력)**: armchk 인덱스의 bank 필드에 카드
   뱅크($00-$1F)를 넣으면 serve 의 `TAM #$20` 이 그대로 카드 ROM 을 매핑한다
   — **리더 코드 무변경, 순수 데이터**. $7E(인덱스+armchk+텍스트 ~6.7KB) +
   $7F(8KB) + 카드 free(총 18,051B 실측 — 연속 run 인벤토리 필요) ≈ 수요 충족.
   카드 free 는 전 씬 공유 자원이므로 초과 씬 전용으로 아껴 배정할 것.
2. 부분 커버리지(들어가는 만큼만 한글, 잔여 일본어) — fail-closed 지만 용어
   일관성 훼손. 비추천.
3. b7.5 현상 유지(탑 전체 일본어) — 최후 fallback.

## 6. 부수 확정 사실

- **segment_a/b(.cdl) 는 혼합 컨텍스트 캡처** — segment_b 의 뱅크 지문이
  seg_290_full 과 사실상 일치($6B 44.9%/$73 53.1%/$77 ~39%/$7C 15~18%).
  482 컨텍스트 근거로 인용 금지. 씬 귀속 CDL 은 seg_<lba>_*.cdl 만 사용.
- segment_c.cdl 은 접근 100% = 장면 로드 포함 오염 (자동 제외 실측).
- 32B 이상 정밀도가 필요한 곳 없음 — 판정 단위가 뱅크(8KB)라 16B 그래뉼로 충분.

## 7. 잔여 리스크 (이 도구가 못 닫는 것)

**씬-고유 상태 의존 소비자** — 전역 블록 밖, 그 씬에만 있는 자산을 상태
의존 경로가 읽는 경우는 정적 비교로 안 잡힌다. 완화: CANDIDATE 는 승인이
아니며, 씬별 CDL cold + **아이템 획득·메뉴 조작을 포함한 강화 게이트**가
여전히 채택 조건이다 (b7 게이트 코스 유지).
