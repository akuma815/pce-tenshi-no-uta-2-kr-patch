## 2. 무엇을 만들고 있나

일본어 원문을 한글로 바꿔 화면에 출력한다. 핵심 난점은 **한글 글리프와 번역
텍스트를 어디에 두느냐**다.

- PCE 시스템 카드의 GETFNT는 일본어 폰트만 안다. 한글은 게임이 직접 공급해야 한다.
- 게임의 RAM bank `$68-$87` 32개는 **전부 소유자가 확정돼 있고 영구 여유 bank는 0개**다.
- 따라서 "글로벌 한글 폰트를 RAM에 상주"시키는 접근은 구조적으로 불가능하다.

**현재 전략(Ziria 모듈 재링크):** 각 모듈이 자기 코드·글리프·텍스트를 소유하고,
모듈이 내려가면 함께 폐기된다. 공용 Work RAM에 영구 코드/글리프를 두지 않는다.

## 3. 절대 규칙

이 규칙을 어긴 시도는 전부 실패했다. §9의 실패 이력이 근거다.

   양쪽에서 참조 0건이 증명된 섹터만 사용한다.

### 미인덱스·래퍼 텍스트 탐지 규칙 (2026-08-30)

Z8 인덱스는 NUL 종료 추출이라 **여러 클래스를 통째로 놓쳤다**. 화면에
일문이 남으면 인덱스부터 의심할 것.

1. **래퍼 사본**: 씬 패키지에 `<제어 1B> <내용> 0F 00` 형태로 한 벌 더
   존재하고 **이쪽이 렌더 소스**다. 접두는 `10`(대사창)·`0D`(줄바꿈 선행)
   등 여러 종, 끝 제어(`\p`=0C, `
`=0D)가 `0F` 로 **대체된 변종**도 있다.
   → 접두 유무 × 끝 제어 3종을 모두 시도해 인덱스 raw 와 정확히 일치할
   때만 채택(fail-closed). 내용 용량은 원본보다 1B 여유.
2. **다중 세그먼트 레코드**: `0F` 로 여러 문장을 이은 레코드는 통째로
   인덱스에 없다(전투 결과 템플릿).
3. **테이블에 흡수된 첫 이름**: `u16 포인터 테이블 + 이름들` 블록에서
   **첫 이름이 테이블과 한 덩어리**로 묶여 누락된다(몬스터명 バルーン).
4. **고정밀 탐지 필터**: 미인덱스 + 미패치 + **서식 토큰(`%s`/`%d`) 포함**
   + SJIS 한자 포함 + 레코드 ≤60B. 느슨하게 잡으면 코드·그래픽이
   2,518건 섞인다(실측).

### 한글 표기 규칙 (사용자 결정)

- **자리표시자 뒤 조사 금지**: `{%s}` 뒤의 은/는/이/가/의/을/를 은 전부

  레지스터는 R0(295,469)·R2(297,294) 뿐이고 **R7/R8 은 0회**. 게임은 스크롤
  레지스터를 아예 쓰지 않고 타일 스트리밍으로 화면을 갱신한다.

  BAT 에서 창 채움 타일 영역을 찾아 BAT 좌표를 얻고, 그 클래스의 화면 rect(정적
  추출값)와의 차이로 원점을 역산한다. 창이 뜰 때마다 자기보정되어 씬·스크롤과 무관.

  **창 테두리 폭**(스크린샷은 채움색 픽셀 전체를, BAT 는 완전한 채움 타일만 잡음).

  6px 를 방치하면 일문이 삐져나오거나 한글이 잘리므로 필수. 상세 = Z11 §4e.

### 카드 미니게임 UI 그래픽 (b29, 2026-10-10 저녁) — 「압축 타일 추정」은 틀렸다

- **구조**: 모듈은 ISO 0xBD5000(섹터 6058)부터 TurboCD RAM 에 raw 적재(RAM 0x1000~0xC000 = ISO 0xBD6000~). VRAM 타일은
  **ISO 0xBE3000 + 타일번호×32 에 선형**(타일 0x400~0x7FF = ISO 0xBEB000~0xBF3000, 32KB 한 장을 전 화면이 공유; 0x402 = 공백 타일).

  조립해 VDC 로 보낸다(ST1/ST2·TIA 로 추정 — `STA $0002/$0003` 버스 쓰기 훅엔 SATB(PC 9174)·화면 지우기(PC 6A37, 타일 0x401 채움)만 잡힘).
  ISO 안에 BAT 원본 raw 는 없음(압축/코드 조립) → **BAT 는 손대지 않고 타일 내용만 교체**하는 방식으로 충분했다.
- **도구** `tools/cardgame_tiles_kr.py`: PCEHawk 스테이트(원본 디스크) VRAM/BAT 덤프(`translation/cardgame/vram/s{3..7}_*`)로 셀→타일→ISO 대응,
