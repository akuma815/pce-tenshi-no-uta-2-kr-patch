# PCE CD판 v1.0(b64) 소스 재빌드

공식 배포 v1.0의 디스크·CUE·수정 시스템 카드를 재현한다. 기존 번역 원장은 수정하지 않았다. 2026-10-16에 누락된 중간 카드 복원 차분, 고정 글꼴, 디스어셈블러 C# 소스, 패처 소스를 추가했다. 원본 게임·BIOS·완성 이미지는 Git에 포함하지 않는다.

## 준비

- Python 3.11 이상과 `python -m pip install -r requirements.txt` (검증 환경의 버전은 검증 JSON에 기록).
- .NET SDK 8.0 (검증 환경: 8.0.422), xdelta3 실행 파일.
- 보유한 원본 단일 BIN과 그 CUE, 일본판 Super System Card 3.0 BIOS. 입력 크기·SHA-256은 `config/rebuild_b64.json`에 고정했다. 512바이트 헤더가 붙은 BIOS는 헤더를 제거한 뒤 검사한다.
- Redump 결과 검증까지 하려면 보유한 원본 Track 02도 준비한다. Redump 트랙 세트만으로 단일 BIN 소스를 대신하는 경로는 검증하지 않았다.

PowerShell에서 경로를 실제 보유 파일로 바꿔 실행한다.

```powershell
python -X utf8 tools/rebuild_b64.py `
  --source-bin 'D:\Owned\Tenshi_no_Uta_II-Datenshi_no_Sentaku_JAP.bin' `
  --source-cue 'D:\Owned\Tenshi_no_Uta_II-Datenshi_no_Sentaku_JAP.cue' `
  --source-bios 'D:\Owned\SystemCard3_original.pce' `
  --xdelta 'D:\Tools\xdelta3.exe' `
  --redump-track02 'D:\Owned\Tenshi no Uta II - Datenshi no Sentaku (Japan) (Track 02).bin'
```

`--redump-track02`는 생략 가능하다. 기본 출력은 새 `build/b64_<시각>/` 디렉터리다. `--output`으로 아직 존재하지 않는 별도 디렉터리를 지정할 수도 있다. 기존 디렉터리를 덮어쓰지 않는다. 원장·소스·원본은 격리된 빌드 디렉터리로 복사하며 기존 세이브나 에뮬레이터 설정은 바꾸지 않는다.

`verification.json`의 `status: PASS`와 각 단계 로그를 확인한다. 기존 `build_btrack_b64_hook_build.py`를 직접 실행하면 입력 경로 준비가 별도로 필요하고 원장 옆 생성 파일을 갱신할 수 있으므로 위 진입점을 사용한다.

## 고정 출력

| 출력 | SHA-256 |
| --- | --- |
| b64 단일 BIN, 523,184,384바이트 | `85d71ed783164a2d305179153f701f193c51d09943066bc4cee94b4bab6e8838` |
| b64 CUE | `468a563775b1705d6876692e683fb2407a3c1eca8e40bf3029a1d725c53b809f` |
| b64 시스템 카드, 262,144바이트 | `5632f388ae2f0fce9e435134ee89b825172e9b2a08bae5f7b5856a9807f21274` |
| Redump Track 02, 22,466,304바이트 | `5098df4d14314e4948c50364628a7306a47434abdbc7d67f4e8261defc7f661c` |

2026-10-16에 GitHub의 기존 v1.0 ZIP을 다시 내려받아 원본에 패치를 적용한 결과도 위 BIN·시스템 카드·Track 02와 일치했다. ZIP SHA-256은 `6b6afac020338584fdb8ced76bff3a0e609418874145bc54ff3683bea0a48fa3`이다. 배포 파일을 교체하거나 버전을 올리지 않았다.

이 검증은 소스 재빌드·패치 적용·해시 비교다. 이번 작업에서 에뮬레이터 실행, 영상 재생, 전체 플레이 검수는 수행하지 않았다. 과거 사용자 완주 보고는 당시 b63에 대한 별도 근거다.

## 추가 입력과 출처

- `assets/bootstrap/SystemCard3_full_v6_from_original.xdelta`: 소유한 원본 BIOS를 소스로 요구하는 12,323바이트 차분. 과거 빌드 체인이 필요로 하는 중간 카드의 정확한 복원용이며 원본 BIOS를 내장하지 않는다.
- `assets/fonts/Galmuri14.ttf`: 기존 작업에 사용한 동일 글꼴. 배포 조건은 `licenses/Galmuri_OFL.md`.
- `tools/huc6280_disasm_verifier/vendor/BizHawk.HuC6280.Disassembler.cs`: 기존 로컬 BizHawk 소스의 `src/BizHawk.Emulation.Cores/CPUs/HuC6280/Disassembler.cs`를 변경 없이 보존했다. 원본 C# 코드의 라이선스 고지는 `licenses/BizHawk_LICENSE.txt`. 전체 에뮬레이터나 C/C++ 코어는 추가하지 않았다.
- `release/app/`: 기존 v1.0 패처의 Python 소스와 빌드 설정. 이번 검증 대상은 코어 출력이며 새 GUI 실행 파일의 바이트 재현은 검증하지 않았다.
- `REBUILD_INPUT_MANIFEST.json`: 공개 소스·번역 원장·복원 입력의 크기와 SHA-256 목록. 공개된 원장 스냅샷은 그대로 유지했다.

## 로컬 정리 시 보존

사용자의 원본 Redump 세트는 게임 폴더의 `Original/` 안에 있다. 루트의 원본 단일 BIN/CUE도 이 빌드의 별도 필수 입력이다. 따라서 **게임 폴더 전체를 삭제하지 않는다.** 외부 보관 사본이 확인되거나 원본을 남기는 별도 정리 절차가 필요하다. 기존 b10 보존 지시와 세이브·편집 기록도 유지한다.

2026-10-16 목록에서 `archive/tools_task0_7/task6_workbook_runtime/node_modules` 재분석 지점 1개를 발견했다. 향후 정리 시 대상의 절대 경로와 재분석 지점 처리를 확인해야 한다. 이번 작업에서는 PCE 게임 폴더의 파일을 삭제하지 않았다.
