## 재현

프로젝트 루트에서 실행한다. 첫 명령은 원고 MD를 유지한 채 TXT/HTML/PNG 복사/ZIP을 재생성하므로 이미 배포한 ZIP의 단순 검증용으로 사용하지 않는다. ZIP 컨테이너 해시는 파일시각에 따라 달라질 수 있고, `SHA256.txt` 는 내부 파일 내용의 기준이다.

```powershell
python -X utf8 tools/build_publication_worklog_20261010.py
python -X utf8 tools/render_publication_worklog_20261010.py
Get-FileHash -Algorithm SHA256 -LiteralPath 'workspace/publication/Tenshi2_KR_Worklog_20261010.zip'
```

렌더 도구 의존성: Windows Edge 설치 경로와 Python `websocket-client`. 게임 에뮬레이터를 호출하지 않는다.
